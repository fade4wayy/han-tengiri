# Витрина ЖК «Хан-Теңири»

3D-витрина квартир: выбор этажа и квартиры, расчёт рассрочки, вид из окна
с реальным рельефом Ала-Тоо и застройкой из OpenStreetMap.

Одностраничное приложение без сборки: весь код, данные и изображения
встроены в `index.html`.

Картография © OpenStreetMap contributors (ODbL). Рельеф SRTM / OpenTopoData.
Рендеры и планировки — материалы застройщика.
